# Skill: Read Memory (System)

## Purpose
Fetch context generated by prior workflow states or subagents from the SQLite blackboard.

## Behavior
1. If a memory key is provided, return the stored data.
2. If no key is provided, list all available keys for the current session.

## Expected Output
Returns a `SkillResult` containing the requested memory data or a list of available keys.
